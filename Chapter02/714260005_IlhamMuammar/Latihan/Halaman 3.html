HyperText Markup Language

    Pengertian HTML

HTML adalah singkatan dari HyperText Markup Language, yaitu bahasa markup yang digunakan untuk membuat struktur halaman web, menampilkan teks, gambar, link, dan elemen lainnya di browser.HTML bukan bahasa pemograman karena tidak bisa membuat fungsi dinamis, tetapi menjadi fondasi utama dalam pembuatan website. File HTML biasanya disimpan dengan ekstensi .html atau.htm.

    Sejarah HTML

Pertama kali diperkenalkan oleh Tim Berners-Lee pada akhir 1991 di CERN untuk memudahkan berbagi dokumen ilmiah.Seiring waktu, HTML berkembang menjadi standar web yang digunakan secara luas. Versi terbaru adalah HTML5, yang mendukung multimedia, grafis, dan aplikasi web modern.

      Fungsi HTML

    HTML memiliki beberapa fungsi utama:

    • Membuat halaman website: Menyusun konten dan struktur halaman web
    • Menampilkan informasi di browser:Browser membaca file HTML dan merender konten agar dapat dilihat pengguna.
    • Membuat hyperlink:Menghubungkan halaman web satu dengan yang lain melalui link
    • Mendukung SEO:Membantu mesin pencari memahami struktur dan konten website

      Komponen HTML

    HTML tersusun dari beberapa komponen penting:

    • Tag:Intruksi yang digunakan untuk menandai elemen, misalnya < p > untuk paragraf, < h1 > untuk judul, < b > untuk teks tebal.
    • Elemen:Gabungkan tag pembuka konten, dan tag penutup.
    • Atribut:Memberikan informasi tambahan pada elemen, misalnya href pada < a > untuk menentukan alamat link

      Hubungan dengan CSS dan JavaScript

    • CSS:Untuk mempercantik tampilan website.
    • JavaSripct:Untuk membuat website lebih interaktif dan dinamis

      Kesimpulan

    HTML adalah fondasi dasar pembuatan website yang memungkinkan developer menyusun konten, membuat link, dan menampilkan informasi di browser. Dengan memahami HTML, pengguna dapat melanjutkan belajar CSS dan JavaScript untuk membuat website yang lebih menarik dan interaktif
